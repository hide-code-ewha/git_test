변수로 색상과 크기 다루기 실습 01 / 03

변수는 작품의 재료를 담는 상자예요.

색상, 크기, 속도처럼 바꾸고 싶은 값을 변수에 담아두면 코드를 매번 고치지 않아도 작품을 쉽게 조절할 수 있어요.

let circleSize = 120;
let circleColor = '#FF5C35';

function draw() {
  // 원을 화면에 그려요
  fill(circleColor);
  circle(200, 150, circleSize);
}
✦ TIP 숫자나 색상 값을 바꾸고 실행해보세요.

나의 첫 번째 도형 ● LIVE

조건문은 상황에 따라 다른 장면을 고르게 해요.

if / else 는 변수의 값을 확인해서, 조건이 참이면 이 코드를, 거짓이면 저 코드를 실행하는 갈림길이에요. 시간(hour) 값 하나로 낮과 밤 장면을 완전히 바꿔볼게요.

let hour = 9;

function draw() {
  if (hour < 18) {
    background('#bfe6ff'); // 낮
  } else {
    background('#1b1b3a'); // 밤
  }
}
✦ TIP hour 슬라이더를 18 언저리에서 움직여 보세요.

낮과 밤 장면 전환 ● LIVE

반복문은 같은 규칙을 여러 번 되풀이해요.

for 문은 count번 만큼 같은 코드를 반복 실행해요. draw()는 p5.js가 1초에 60번씩 자동으로 다시 호출해주기 때문에, 반복문과 만나면 움직이는 패턴을 만들 수 있어요.

let count = 8;

function draw() {
  background('#f3f0e8');
  for (let i = 0; i < count; i++) {
    // count번 반복해서 원을 그려요
    circle(x(i), y(i), 30);
  }
}
✦ TIP count를 늘려서 원 개수를, speed로 움직임 속도를 바꿔보세요.
